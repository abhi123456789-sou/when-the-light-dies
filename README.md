# WHEN THE LIGHT DIES

> A story-driven psychological horror game where every choice has consequences.

---

## 🎮 About The Game

**WHEN THE LIGHT DIES** is a story-driven psychological horror game built for the web.

The game focuses on:

- Exploration
- Mystery
- Psychological horror
- Story progression
- Player choices
- Environmental storytelling
- Puzzles
- Survival
- Dynamic events
- Multiple endings

The central idea of the game is simple:

**When the light disappears, the rules change.**

---

## 🕯️ Core Concept

Light is not just a visual element.

It is part of the game's core mechanics.

As the player's light decreases, the world can change.

```text
LIGHT
  ↓
DARKNESS
  ↓
FEAR
  ↓
UNKNOWN EVENTS
  ↓
PLAYER DECISIONS
  ↓
CONSEQUENCES
  ↓
DIFFERENT STORY PATHS
  ↓
MULTIPLE ENDINGS
